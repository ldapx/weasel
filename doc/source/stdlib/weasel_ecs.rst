weasel_ecs
==========

.. das:module:: weasel_ecs

.. note::
   The ``weasel_ecs`` module no longer exists as a gameplay
   import. ``EcsSystem`` now lives in the ``weasel`` facade
   and game systems extend ``GameSystem`` (``class System :
   GameSystem``).

   See the migration guide for the lifecycle contract
   (``on_start`` / ``update`` / ``fixed_update`` /
   ``late_update`` / ``on_stop``).
